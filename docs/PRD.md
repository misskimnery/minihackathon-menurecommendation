# PRD — 오늘 뭐 먹지? (AI 메뉴 추천)

작성일: 2026-09-22 / 타임박스: **2시간** / 2차 코딩데이 미니 해커톤

## 1. 목표

밥 메뉴를 고르기 귀찮은 사람이 **버튼 몇 번만 누르면**, 지금 상황에 맞는
메뉴 3가지를 이유와 함께 받아보는 1페이지 서비스.

## 2. 성공 기준 (Definition of Done)

- [ ] 배포된 공개 URL에서 Gemini 추천이 실제로 동작
- [ ] 입력 → 로딩 → 결과 카드까지 한 흐름이 끊기지 않음
- [ ] 모바일(375px)에서 레이아웃 안 깨짐
- [ ] API 키 없음 / 호출 실패 / 응답 파싱 실패 각각 사용자에게 보이는 문구가 있음

## 3. 화면 (2개)

| # | 화면 | 내용 |
|---|---|---|
| S1 | **조건 입력 폼** | 기분 · 예산 · 함께 먹는 사람 · 날씨 = 선택형 버튼 / 못 먹는 음식 = 칩 다중선택 + 직접입력 한 칸 |
| S2 | **AI 결과** | 한 줄 총평 + 메뉴 카드 3장 (이름·이모지·추천 이유·어울리는 사이드·음료·대략 가격) + "다시 추천받기" |

같은 페이지 안에서 상태만 전환한다 (라우트 추가 없음).

## 4. 입력 항목

- **기분** — 지침 / 스트레스 / 기분 좋음 / 무난 / 우울 / 설렘
- **예산** — 1만원 이하 / 1~2만원 / 2~3만원 / 상관없음
- **함께** — 혼밥 / 친구 / 연인 / 가족 / 회식
- **날씨** — 더움 / 추움 / 비 / 맑음 / 흐림
- **못 먹는 음식** — 해산물·매운음식·유제품·돼지고기·소고기·견과류·오이 칩 + 직접입력

## 5. AI 연동

- `POST /api/recommend` (Next.js Route Handler) 에서만 Gemini 호출. 키는 **서버에만** 존재.
- 모델 `gemini-2.5-flash`, `responseMimeType: application/json` + `responseSchema` 로 구조 고정.
- 스키마가 거부되면 스키마 없이 1회 재시도 → 응답에서 ```json 백틱 제거 후 파싱.
- 환경변수 `GEMINI_API_KEY` (없으면 결과 화면 대신 설정 안내).

**응답 형식**

```json
{ "headline": "비 오는 날 혼자 몸 녹이기 좋은 메뉴로 골랐어요",
  "menus": [{ "name":"김치찌개","emoji":"🍲","reason":"...",
              "side":"계란말이","drink":"보리차","priceHint":"9,000원대" }] }
```

## 6. 기술 스택

Next.js 16 (App Router) + TypeScript + Tailwind 4 + Gemini API + Vercel 배포.
SDK 없이 `fetch` 로 REST 호출 — 의존성 0개 추가.

## 7. Non-goals (이번 2시간에 안 하는 것)

- 로그인 / 회원가입 / 사용자별 저장
- 추천 결과 히스토리, 즐겨찾기, 공유 링크
- 지도·식당 검색·실제 주문 연동
- 실시간 날씨 API 자동 감지 (날씨는 사용자가 직접 선택)
- 다국어, 다크모드 토글(OS 설정만 따름)
- 테스트 코드, 애널리틱스, OG 이미지 자동 생성
- `/` 외 추가 라우트
